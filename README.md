# Fluixer 0.2.0

Interactive liquid/gas tube pattern design with STEP import, image extraction,
spatial brush painting, geometric compensation, animation and CSV export.

Website deployment uses Docker, Flask and Gunicorn. All application pages and
APIs require a shared invited-preview username and password configured on the
hosting platform. Do not commit credentials.

See [Render setup](docs/render-deployment.md) for environment variables and
validation steps. The website has not yet been deployed or tested on Render.

Third-party font and model licenses are included beside the assets. No license
for the application source is granted by this repository.
